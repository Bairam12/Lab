# Вариант 5 — вход в интернет-магазин (гость / пользователь)
Откройте `index.html` двойным кликом. Тестовые аккаунты: `student` / `Test-Pass-123`, `aigerim` / `Test-Pass-456`.

**Файлы:** `index.html` (разметка), `style.css`, `app.js` (интерфейс), `server-sim.js` (эмуляция серверного обработчика), `crypto-utils.js` (хеширование/случайные токены).

**Схема:** форма → `POST /login` (проверка хеша PBKDF2) → создаётся сессия с токеном → `GET /me`, `/cart`, `/orders/:id` проверяют сессию → `POST /logout` уничтожает сессию.

| Запрос | Кто | Ответ |
|---|---|---|
| GET /products | гость | 200 |
| POST /login | гость | 200 / 400 пустые поля / 401 неверные данные / 429 много попыток |
| GET /me, /cart; POST /cart, /checkout | вошедший | 200 / 401 |
| GET /orders/:id | владелец заказа | 200 / 403 чужой / 404 |

**Гость:** видит каталог, кнопки покупки заблокированы. **Пользователь:** корзина, оформление заказа, имя, «Выйти».
**Меры защиты:** хеш пароля с солью, одинаковое сообщение для неверного логина и пароля, лимит 5 попыток, проверка прав в «серверном» коде, вывод через `textContent`.
**Творческое задание:** индикатор оставшегося времени сессии (красный за минуту до конца) — пользователь заранее видит конец сессии.
**Ограничение:** прототип с эмуляцией сервера, настоящей защиты нет (см. README в корне).
