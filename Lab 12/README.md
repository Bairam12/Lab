# Лабораторная работа №12 — JWT, OAuth/OIDC, сессии
Индивидуальные задания: **вариант 5**, **вариант 12**, **вариант 18**.

| Папка | Вариант | Уровень | Зависимости |
|---|---|---|---|
| variant-05-shop | 5 — вход в интернет-магазин | базовый | нет |
| variant-12-forum | 12 — мини-форум | средний | нет |
| variant-18-oidc | 18 — OIDC, authorization code + PKCE | повышенный | `npm install` (openid-client) |

В каждой папке: `README.md` (запуск, маршруты, меры безопасности, творческое задание), `tests.js` (тестовые сценарии), `lib/` (сессии, пароли, HTTP-утилиты).
Пароли в репозитории не хранятся: только хеши тестовых аккаунтов.

## Запуск
Установите Node.js (LTS) с https://nodejs.org, затем дважды щёлкните `start.bat` внутри нужного варианта — или `start-all.bat` в этой папке, чтобы запустить все три сразу.

| Вариант | Адрес |
|---|---|
| 5 — магазин | http://localhost:3005 |
| 12 — форум | http://localhost:3012 |
| 18 — OIDC | http://localhost:3018 |
