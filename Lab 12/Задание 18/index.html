Учебный портал

Гость

Учебная имитация OpenID Connect: роль провайдера играет страница provider.html (файлы idp-core.js, provider.js). Поток — authorization code + PKCE, подпись ID-токена RS256 проверяется настоящей криптографией браузера. Настоящего провайдера (Google и т. п.) здесь нет.

Вход через OpenID Connect

Вы перейдёте на страницу провайдера. Пароль вводится только там — портал его не видит.
