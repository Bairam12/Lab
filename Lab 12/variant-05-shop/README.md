# ЛР №12 — Вариант 5: вход в интернет-магазин (гость / пользователь)

Стек: Node.js 18+ (без внешних зависимостей), HTML/CSS/JavaScript.

## Как запустить
1. Один раз установите Node.js (версия LTS): https://nodejs.org — обычная установка, «Next» до конца.
2. Дважды щёлкните по файлу **`start.bat`** в этой папке. Откроется чёрное окно сервера и браузер с адресом **http://localhost:3005**.
3. Работайте в браузере. Чёрное окно не закрывайте — пока оно открыто, сервер работает. Чтобы остановить сервер, закройте окно.

Автотесты: в папке проекта выполните `npm test` (для варианта 18 — офлайн-проверки защиты и сессий).

Нельзя открывать `public/index.html` двойным кликом или через Live Server: вход выполняет сервер на Node.js.
Если браузер не открылся сам, откройте адрес вручную. Если пишет, что порт занят, — сервер уже запущен в другом окне.

## Как это работает
`POST /api/login` → сервер проверяет хеш → создаёт серверную сессию → отправляет cookie `sid` (HttpOnly, SameSite=Lax; Secure при `COOKIE_SECURE=1` на HTTPS) → `GET /api/me`, `/api/cart` проверяют сессию → `POST /api/logout` уничтожает сессию.

| Маршрут | Доступ | Ответы |
|---|---|---|
| GET /api/products | гость | 200 |
| POST /api/login | гость | 200 / 400 пустые поля / 401 неверные данные / 429 много попыток |
| GET /api/me, /api/cart; POST /api/cart, /api/checkout | вошедший | 200 / 401 |
| GET /api/orders/:id | только владелец заказа | 200 / 403 / 404 |
| POST /api/logout | любой | 200 |

**Гостевой интерфейс:** каталог виден, кнопки «В корзину» заблокированы, показана форма входа.
**Пользовательский интерфейс:** корзина, оформление заказа, имя пользователя, кнопка «Выйти».

## Меры безопасности
- серверная сессия, идентификатор — 256 бит случайности, новая сессия при каждом входе;
- пароли — scrypt; сообщение об ошибке одинаково для неверного логина и пароля;
- ограничение 5 неудачных попыток в минуту;
- проверка прав на сервере (скрытие кнопок — только удобство);
- вывод через `textContent` (защита от XSS) и CSP без inline-скриптов;
- проверка `Origin` + SameSite для защиты от CSRF.

## Творческое задание
Индикатор оставшегося времени сессии рядом с именем пользователя (красный, когда осталась минута). Обоснование: пользователь заранее видит, что сессия закончится, и не теряет заполненные данные; при истечении интерфейс сам возвращается в гостевой режим.

## Допущения
Данные (корзины, заказы, сессии) хранятся в памяти и пропадают при перезапуске сервера — для учебного прототипа этого достаточно.
