# Вариант 12 — мини-форум (гостевой просмотр, вход для публикации, выход)
Откройте `index.html` двойным кликом. Аккаунты: `alice` / `Test-Pass-111`, `bob` / `Test-Pass-222`, `moderator` / `Test-Pass-333`.

**Файлы:** `index.html`, `style.css`, `app.js` (интерфейс), `server-sim.js` (эмуляция серверного обработчика), `crypto-utils.js`.

| Запрос | Кто | Ответ |
|---|---|---|
| GET /posts | гость | 200 |
| POST /login | гость | 200 / 400 / 401 / 429 |
| POST /posts | вошедший | 201 / 400 / 401 |
| DELETE /posts/:id | автор или модератор | 200 / 401 / 403 / 404 |
| GET /audit | модератор | 200 / 401 / 403 |

**Меры защиты:** хеш пароля, права проверяются в «серверном» коде (кнопка «Удалить» в интерфейсе — лишь удобство), текст сообщений выводится как текст (скрипт в сообщении не выполнится), лимит длины 500 символов, лимит попыток входа.
**Творческое задание:** журнал попыток входа/выхода для модератора — помогает заметить подбор пароля.
**Ограничение:** прототип с эмуляцией сервера, настоящей защиты нет (см. README в корне).
