# ЛР №12 — Вариант 12: мини-форум (гостевой просмотр, вход для публикации, выход)

Стек: Node.js 18+ (без внешних зависимостей), HTML/CSS/JavaScript.

## Как запустить
1. Один раз установите Node.js (версия LTS): https://nodejs.org — обычная установка, «Next» до конца.
2. Дважды щёлкните по файлу **`start.bat`** в этой папке. Откроется чёрное окно сервера и браузер с адресом **http://localhost:3012**.
3. Работайте в браузере. Чёрное окно не закрывайте — пока оно открыто, сервер работает. Чтобы остановить сервер, закройте окно.

Автотесты: в папке проекта выполните `npm test` (для варианта 18 — офлайн-проверки защиты и сессий).

Нельзя открывать `public/index.html` двойным кликом или через Live Server: вход выполняет сервер на Node.js.
Если браузер не открылся сам, откройте адрес вручную. Если пишет, что порт занят, — сервер уже запущен в другом окне.

## Маршруты
| Маршрут | Доступ | Ответы |
|---|---|---|
| GET /api/posts | гость (открытый просмотр) | 200 |
| POST /api/login | гость | 200 / 400 / 401 / 429 |
| POST /api/posts | вошедший | 201 / 400 / 401 |
| DELETE /api/posts/:id | автор или модератор | 200 / 401 / 403 / 404 |
| GET /api/audit | только модератор | 200 / 401 / 403 |
| POST /api/logout | любой | 200 |

## Меры безопасности
- серверная сессия + cookie HttpOnly/SameSite=Lax; пароли хранятся как scrypt-хеши;
- публикация и удаление проверяются на сервере (401 без входа, 403 для чужого сообщения);
- текст сообщений выводится через `textContent`, поэтому `<script>` в сообщении безопасен;
- ограничение длины сообщения (500 символов), ограничение попыток входа, CSP.
