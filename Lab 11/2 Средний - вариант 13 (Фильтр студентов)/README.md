# Лабораторная №11 — вариант 13 (средний): Фильтр студентов

StudentList получает массив студентов через props; state хранит поисковую строку и выбранную группу и фильтрует список.
StudentCard получает name, group, specialty через props. Есть сообщение при пустом результате и кнопка сброса фильтров.

Запуск: `npm install`, затем `npm run dev`.
