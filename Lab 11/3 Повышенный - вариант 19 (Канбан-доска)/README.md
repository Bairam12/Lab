# Лабораторная №11 — вариант 19 (повышенный): Канбан-доска

TaskCard получает задачу через props; родитель KanbanBoard хранит карточки по статусам и перемещает их кнопками ← →.
Есть добавление с проверкой пустого ввода и длины, удаление, сброс доски и сохранение в localStorage.

Запуск: `npm install`, затем `npm run dev`.
